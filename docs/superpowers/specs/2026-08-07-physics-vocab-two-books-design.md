# 接入物理词表并重做「学习」页信息架构

2026-08-07

## 背景

现有闪卡收录《IGCSE 自然科学英语核心词汇表》164 词分 8 章，构建时再由
`extra.py` 追加第 9 章「衔接课程补充」6 词，**合计 170 词**；另有 10 组答题句型、
1 节课前预习。现在要接入《Cambridge IGCSE Physics 0625 核心词汇表》。

两个问题必须一起解决：

1. 新词表 162 词、11 章，与现有词表有 51 个同名词。天真合并会让
   `S.prog` / `BY_W` 这两个以英文词为 key 的结构互相覆盖。
2. 「学习」页当前是竖排卡片流，8 章已经要滚 3 屏多；再加 11 章会长到没法用。

## 目标

- 物理 162 词享有与现有词表同等待遇：音标、音节切分、词根助记、例句翻译思路、
  逐音节跟读、间隔重复。
- 两套词表进度独立、互不干扰。
- 「学习」页在 11 章的规模下控制在 2.5 屏以内。
- 保持单文件、零外部请求、可离线打开。

## 非目标

- 不重新划分现有 164 词的章节归属。它本来就是综合词汇表（含 34 化学词、
  20 生物词、15 物理基础词、75 通用词），保持原样。
- 不引入第三本词书。
- 不改动底部 Tab 栏的四个入口。

## 决策记录

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 词库结构 | 两本词书，学习页顶部切换 | 51 个同名词各自独立成条，物理的 `pressure` 配物理例句 |
| 两本书的标签 | 「科学」/「物理」 | 现有表不是纯化学，叫「化学」会错标 20 个生物词和 75 个通用词 |
| 章节卡形态 | 2 列紧凑网格 | 11 章占 6 行；竖排大卡要占 11 屏高 |
| 章节进度指示 | 卡底内缩细条 | 设计稿实测：微型环在 `7/16` 与 `5/12` 之间几乎分辨不出，只有满环能认；细条一列扫下来可比 |
| 科目切换 | 分段控件 + 左右滑动 | 学习/词表/句型三页共用同一状态，手势复用卡片页已有写法 |
| 词表搜索 | 输入关键词时自动跨科 | 同名词（`pressure`）两科例句可直接对比 |
| 复习队列 | 跟随当前科目 | 另一科到期数以红点提示，不混队 |
| 进度存储 | 词条 id 加科目前缀 | 见下方「被否掉的方案」 |
| 内容范围 | 音标/音节 + 词根助记 + 翻译思路 + 10 组句型，全做 | 与现有词表对齐 |

### 被否掉的方案

- **`S.prog` 仍按裸词、两科共享同名词进度**：改动最小，但与「进度分开记」冲突，
  且 `BY_W` 会互相覆盖，章节完成度统计会错。
- **两科各用一个 localStorage key**：进度天然隔离，但语速/主题/音色会分裂成两份，
  且「另一科到期数」提醒要同时读两个 key，更绕。
- **按学科重切成化学/物理/生物三本**：分类最准，但需逐词重新归类，且 75 个通用词
  的「共享进度」会让存储和统计复杂度陡增。

## 数据模型

### `src/data.json` 顶层结构

```
{
  "books": [
    { "id": "sci", "cn": "科学", "credit": "IGCSE 自然科学英语核心词汇表",
      "sections": [ …9 章 / 170 词… ], "frames": [ …10 组… ] },
    { "id": "phy", "cn": "物理", "credit": "Cambridge IGCSE Physics 0625 核心词汇表",
      "sections": [ …11 章 / 162 词… ], "frames": [ …10 组… ] }
  ],
  "lessons": [ … ]
}
```

`frames` 和 `sections` 从顶层挪进各自的 book。`lessons` 留在顶层，靠 `book`
字段归属。

### 词条 id

构建时给每个词条补 `id`，格式 `<bookId>:<w>`，例如 `sci:pressure`、`phy:pressure`。

- `S.prog` 的 key 从裸词改成 id
- `BY_ID` 取代 `BY_W`，跨全部书建索引
- `ALL` 变成按当前书过滤的 `curWords()`

### 物理词表的两处去重

PDF 内 `temperature` 与 `current` 各出现两次。保留定义性更强的一条：

| 词 | 保留 | 丢弃 |
| --- | --- | --- |
| `temperature` | 热学章「Temperature measures how hot or cold something is.」 | 测量与数据章「Measure the temperature of the water.」 |
| `current` | 电与磁章「Current is the rate of flow of charge.」 | 测量与数据章「Current is measured in amperes.」 |

「测量与数据」章因此从 19 词降为 17 词，物理书合计 162 词。

### 音标/助记的复用

51 个同名词的音标与音节切分完全相同（`pressure` 就是 `pressure`），
所以 `PHON` 保持按**裸词**索引的全局字典，两本书共用，只需新写 111 条。
分科目的只有释义 `zh` 与例句 `ex`/`exzh`。

翻译思路则必须按书分开——科学书的 `pressure` 例句和物理书的不是同一句，
所以 `TRANS` 按书各持一份，构建时挂到对应 book。

### `src/build.py`

- `build_data()` 产出 `{books, lessons}`；科学书沿用现有 `parsed.json`/`data.json`
  缓存路径，物理书读 `parsed_phy.json`，同样支持「无 parsed 文件时吃 data.json 缓存」

### 构建期校验

现有三道全部保留并扩到两本书，另加两道：

1. 音节拼写拼回原词必须一致（已有）
2. `final` 各段拼接必须等于 `exzh`（已有）
3. 课时 `vocab` 引用的词必须在目标书里查得到（已有，改为按前缀定位书）
4. **新增**：同一本书内 `id` 不重复——这道会自动捕获 `temperature`/`current` 那类问题
5. **新增**：`PHON` 必须覆盖两本书的全部裸词，缺哪个直接报错

翻译思路缺失仍只打印提醒、不中断构建，允许分批补。

### 科目切换的三种入口

学习页、词表页、句型页**共用同一个当前科目状态**（`S.set.book`），三页顶部都放
同一个 `.bookbar` 分段控件，另一科有到期复习时在其标签上挂红点+数字。

三页还都支持**左右滑动切换科目**。手势复用卡片学习页已有的写法
（`tpl.html:1397`）：`touchstart` 记起点，`touchend` 判断
`|dx| ≥ 55 && |dx| > |dy| × 1.6`，左滑去下一本、右滑去上一本，到头不循环。
监听挂在 `main#view` 上，`{passive:true}`。`#study` 是 `position:fixed` 的独立
覆盖层，其自身的左右滑动（切上/下一张卡）不受影响。

### 词表页

- 顶部 `.bookbar`，默认只列当前科目的章节分组
- **搜索时自动跨科**：搜索框一有关键词，就把另一科的命中结果追加成一个独立分组，
  组头标明科目（如 `物理 · 密度、压强与流体 · 1`）。清空关键词即回到单科视图
- 这样搜 `pressure` 能一次看到科学书和物理书两条，直接对比例句
- 「遮住中文」开关行为不变

### 句型页

- 顶部 `.bookbar`，显示当前书的 10 组句型
- 句型不参与搜索，无跨科逻辑

### 设置页

- 「学习记录」箱体分布按当前书统计
- 「清空学习进度」文案改为「清空全部学习进度（两科）」，避免误解作用范围
- 页脚来源文案按书切换，取自 book 的 `credit` 字段

底部 Tab 栏不变，仍是四个入口。

### 状态与迁移

- 当前书存在 `S.set.book`（`'sci' | 'phy'`，默认 `'sci'`），刷新后停在上次那本
- **迁移**：`load()` 检测 `raw.prog` 中不含 `:` 的裸词 key，整体改写成 `sci:` 前缀
  后写回。幂等，跑一次即稳定
- `S.les`（课时勾选状态）按课时 id 存，不受影响

## 课前预习的跨书取词

衔接课程有两门（化学、物理）。课时按 `book` 字段归属：物理课挂在物理书下，
化学课挂在科学书下。

第 3 节「扩散、布朗运动与气体规律」属于物理课，但它的 12 个词横跨两本：

- `pressure`、`volume`、`kinetic energy`、`temperature` 等 5 词用物理书自己的
  词条，例句是物理语境
- `diffusion`、`Brownian motion`、`concentration`、`collision`、`random`、
  `net movement`、`relative molecular mass` 7 词只在科学书里，写成
  `"sci:diffusion"` 跨书引用

跨书引用的词进度记在其所属书（`sci:diffusion`），因此不计入物理书的进度环，
但预习卡自己的 `d/12` 完成度照实统计。这是预期行为：那些词本来就属于科学书。

## 实施顺序

内容录入量大（111 条音节助记 + 162 条翻译思路），分四步落地，每步结束
`python3 src/build.py` 都能跑通、`index.html` 都可用：

1. **管道**：解析 PDF、`data.json` 改 books 结构、词条补 `id`、`build.py`
   五道校验就位。此时物理书词条已有释义例句，但缺音标——用一份占位 PHON
   让构建通过，并在输出里报告缺口数。
2. **界面**：`.bookbar` 分段控件 + 左右滑动手势（三页）、进度环/今日任务/预习
   按书过滤、章节网格、词表跨科搜索、句型页跟随、设置页文案、localStorage
   迁移。此时两本书都能正常学。
3. **音标与助记**：`phon_phy.py` 111 条，撤掉占位，第 5 道校验转为硬失败。
4. **翻译思路与句型**：`trans_phy.py` 162 条 + `frames_phy.py` 10 组。可分批。

第 1、2 步是骨架，必须一起验收；第 3、4 步是内容填充，可独立推进。
