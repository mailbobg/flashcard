# 词表页新增「测试」功能

2026-09-02

## 背景

闪卡现在只有一种练习方式：翻卡片自评（记得 / 模糊 / 忘记）。自评测的是「认得出」，
不测「想得起」和「写得出」。IGCSE 考试要手写单词，拼写是硬需求。

调研了主流做法（百词斩、扇贝、墨墨、SpellIELTS、Anki），共识是两条：
**输入测回忆、选择只测辨认**，输入更深；但**判分必须宽容**，否则用户会被格式差异劝退。

## 目标

- 在词表页加一个测试入口，测「当前正在看的这批词」
- 覆盖听、认、写三个方向
- 判分完全可靠，不出现「答对却判错」
- 结果喂回现有的间隔重复，不另起一套进度
- 保持单文件、零外部请求、可离线打开

## 非目标

- 不做「输入中文」判分。见下方决策记录
- 不新增 Tab，不改动学习页与句型页
- 不做排行榜、成就、连续打卡这类外部激励

## 决策记录

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 英→中的作答方式 | 四选一 | 词库的 `zh` 是「陈述；直接写出」「重力作用/引力」这类多说法释义，输入中文无法可靠判分；手机上打中文也慢。主流 App 这个方向都用选择题 |
| 中→英、听写 | 输入 | 答案唯一，可机器判分，可 diff 高亮 |
| 题型怎么选 | 默认跟着记忆盒子自动升级，也可手动锁定 | 复用现有 `box 0-5`；想专练某一种时能锁死 |
| 一轮题量 | 10 题 | 拼写要手打，10 题约 2-3 分钟，适合碎片时间 |
| 测试范围 | 当前筛选出的词 | 复用词表页已有的科目切换与跨科搜索，语义自然 |
| 进度 | 直接喂 `grade(id, g)` | 测试结果就是复习结果，不该分裂成两套记录 |
| 动作按钮位置 | 放在可滚动正文里，不做固定底栏 | iOS 键盘弹起时只缩视觉视口不缩布局视口，固定底栏会躲到键盘后面 |
| 奖励 | 音效 + 动效，随连对升级 | 每题都放烟花等于没有奖励 |
| 音效实现 | Web Audio 现场合成 | 不引入音频文件，零字节、零外部请求 |

### 被否掉的方案

- **英→中也用输入 + 宽松匹配**：把 `zh` 按 `；/（）` 拆成多个可接受答案。仍会误判
  写同义词、写得更详细的情况，且手机打中文成本高。
- **英→中输入 + 自评（Anki 式）**：没有误判，但靠自律，累的时候容易随手点「对」。
- **三种都做、设置里选**：三套判分逻辑都要维护，还多一个用户要理解的设置项。

## 题型

题型由词条当前的记忆盒子决定，随复习推进自动升级：

| 盒子 | 题型 | 出题 | 作答 | 朗读时机 |
| --- | --- | --- | --- | --- |
| 0–1 | 辨义 | 英文 + 音标 | 四选一中文 | 出题即读 |
| 2–3 | 拼写 | 中文释义 | 输入英文 | 提交后读（对错都读） |
| 4–5 | 听写 | 只有喇叭，可重复播放 | 输入英文 | 出题即读 |

听写题在喇叭下方用弱一级的颜色显示中文释义作为兜底 —— 实在听不出来时有个抓手，
但视觉层级要明显低于题面，不能喧宾夺主。

### 干扰项（辨义）

从**同一本书**里抽，优先同章，同章不足 3 个则退回全书。

**必须排除与答案语义重叠的词**：把释义按 `；;、/／,，` 拆块、去掉括号里的限定语，
两边有任一块相同就不能做干扰项。否则会出现 `potential difference`「电势差/电压」
的选项里混进 `voltage`「电压」，两个都对。全库 356 词验证过，都能凑出 3 个干净干扰项。

## 判分

### 归一化（拼写 / 听写）

比对前把大小写、空格、连字符全部抹平：

```js
const norm = s => s.toLowerCase().replace(/[-–—\s]/g, '');
```

`–` 是 U+2013，词库里 `distance–time graph`、`speed–time graph` 用的就是它；
还有 `half-life`、`light-year`、`gravitational field strength` 这类。不归一化会误杀。

验证过的边界：

| 答案 | 输入 | 判定 |
| --- | --- | --- |
| `distance–time graph` | `distance time graph` | ✓ |
| `half-life` | `halflife` | ✓ |
| `gravitational field strength` | `Gravitational Field Strength` | ✓ |
| `specific heat capacity` | `specific heat capacty` | ✗ 真拼错 |

### 错误展示

字符级 LCS diff：正确答案里用户漏掉的字母标绿，用户多写/写错的字母在「你写的」里标红。

### 提示

- 点一次「首字母提示」：露出每个词的首字母与长度（`g_________ f____ s______`）
- 「听发音」随时可点
- **用过提示的词即使答对也只按「模糊」记**，不给满级晋升

### 喂回间隔重复

| 情况 | `grade(id, g)` |
| --- | --- |
| 答对、没用提示 | `2`（记得） |
| 答对、用了提示 | `1`（模糊） |
| 答错 | `0`（忘记） |

## 轮次

一轮 10 题。词池 = 进入测试时的筛选结果，进入时打乱一次，用游标 `POOLI` 顺序取。

结果页：

```
        8/10
第 2 轮 · 用时 1:47 · 最长连对 5
      这批还剩 155 词没测

[ 只练错题 ]  [ 下一轮 ]        ← 有错题时
[      重做本轮      ]
```

- **下一轮**：游标前进，从同一批词里接着取 10 个（不重复）；取完自动重洗、从头开始
- **重做本轮**：游标不动，同一批词再来一遍
- **只练错题**：把错题作为新词池重新开始

## 奖励

全部用现有设计令牌，深浅色自动适配；整体包在 `prefers-reduced-motion` 里，
系统开了减弱动效就只留静态。

| 时机 | 音效 | 动效 |
| --- | --- | --- |
| 答对 | 三音上行琶音 | 打勾自己画出来（`stroke-dashoffset`）+ 反馈卡弹入 |
| 连对 ≥2 | 起始音随连对数升高 | 顶栏出现「连对 N」徽章；≥5 从琥珀变绿 |
| 连对 ≥5 | 多加一个八度音 | — |
| 答错 | 低沉短音 | 输入框横向抖动 |
| 满分 | 五音上行 | 14 片彩纸从中心炸开，900ms，用 App 自己的 4 个强调色 |

**音效用 Web Audio 现场合成**（`OscillatorNode` + `GainNode`），不引入任何音频文件。
`AudioContext` 在首次 `pointerdown` 时创建并 `resume()` —— iOS 要用户手势才解锁。

答对时**先响音效、340ms 后再朗读单词**，否则两者会糊在一起。

## 界面

### 入口

词表页顶部，科目切换控件下方：

```
┌────────────────────────┐
│   科学     │    物理     │
├────────────────────────┤
│  [ 测试这 175 个词 → ]  │   ← 文案随筛选结果变
│  [ 搜索…  ] [ 遮住中文 ] │
├────────────────────────┤
│  1. 题目指令词           │
│  …                      │
```

测试按钮在搜索框**上方**。范围就是当前筛选结果：切科目、搜关键词、都会改变它。

### 答题页

`position:fixed; inset:0` 的覆盖层，与现有卡片学习页同级。结构：

```
[×]  ▓▓▓░░░░░  连对 3  4/10     ← 顶栏
─────────────────────────────
 拼写 · 中译英                   ← 可滚动正文
 电与磁
 电势差/电压
 [ 输入英文            ]
 [首字母提示] [听发音]
 [      提交      ]              ← 动作按钮也在正文里
─────────────────────────────
```

**不做固定底栏。** iOS 键盘弹起时只缩小视觉视口、不缩小布局视口，
`position:fixed` 的底栏会整个躲到键盘后面点不到。按钮紧跟输入框，
键盘弹起时正好在拇指上方，一下都不用滚。正文底部留 `env(safe-area-inset-bottom)`。

答完题后把「下一题」`scrollIntoView({block:'nearest'})`，避免它留在折叠线以下。

### 题型选择器

答题页底部一条固定的分段控件，顺序 **拼写 / 辨义 / 听写 / 智能**，默认选中「智能」
（跟记忆盒子自动升级）。选中其余三项之一即锁死题型，当前这道题立即按新题型重绘。

**输入框获得焦点时整条收起**（下滑淡出），失焦或答完题再回来。理由：打字时用不到它；
更重要的是 iOS 键盘弹起时固定底栏会飘到键盘上方，正好压住「提交」。
辨义题没有输入框，这条一直显示。

### 答题页的其他细节

- 提交后把用过的「提交」按钮移除，避免和「下一题」两个主按钮并排
- 答完题把「下一题」`scrollIntoView({block:'nearest'})`

### 设置

设置页「朗读」一组里加一个开关：**音效**（答对答错的提示音），默认开。
存 `S.set.sfx`。与现有「自动朗读」并列。

## 顺带修一个既有 bug

`src/tpl.html:146`：

```css
#app{height:100dvh;height:100vh}     /* 现状：后写的 100vh 生效 */
#app{height:100vh;height:100dvh}     /* 应该：100vh 兜底，支持 dvh 的用 dvh */
```

两条顺序写反了。iOS Safari 的 `100vh` 是**不含底部地址栏**的大视口，所以在 Safari 里
正常浏览时底部 Tab 栏会被 Safari 自己的地址栏压住。加到主屏幕当 PWA 用没有地址栏，
所以一直没暴露。

同时给 viewport meta 加 `interactive-widget=resizes-content`（Android Chrome 会把
键盘算进视口，iOS 忽略该值，无副作用）。

## 验收

- 从词表页点「测试这 N 个词」进入，N 与当前筛选结果一致
- 三种题型都能正常出题、作答、给反馈
- 辨义题的四个选项里，没有任何一个与正确答案语义重叠
- `distance–time graph` 输入 `distance time graph` 判对；`specific heat capacty` 判错
- 用了提示后答对，记为「模糊」而非「记得」
- 一轮 10 题；「下一轮」与上一轮零重叠；「重做本轮」取到同一批
- 测试结果反映到词表页的进度圆点与学习页的进度环
- 375×430 视口（模拟键盘弹起）下，提示按钮与提交按钮都可见可点
- 题型选择器顺序为 拼写 / 辨义 / 听写 / 智能，默认「智能」；锁定后当前题立即重绘
- 输入框获得焦点时题型选择器收起，失焦或答完题后回来
- 提交后页面上只剩「下一题」一个主按钮
- 系统开启「减弱动效」时，动画全部静止但功能不受影响
- 设置页关掉「音效」后，答题不出声（朗读不受影响）
- 断网打开 `index.html` 功能完整
